# Profile sections: where to read and edit

LinkedIn changes its layout often. Treat these as hints and verify against the live page.

| Section | Read | Edit |
|---|---|---|
| Intro (name, headline, location) | `/in/me/` top card | Pencil icon on the top card |
| About | `/in/me/` About card | Pencil icon on the About card |
| Experience | `/in/me/details/experience/` | Pencil per entry, or "+" to add |
| Education | `/in/me/details/education/` | Same pattern |
| Skills | `/in/me/details/skills/` | Pencil / "Add skill" |
| Licenses & certifications | `/in/me/details/certifications/` | Same pattern |
| Projects | `/in/me/details/projects/` | Same pattern |
| Languages | `/in/me/details/languages/` | Same pattern |
| Featured, Publications, Honors, Courses | `/in/me/details/<name>/` | Same pattern |

## Reading tips
- Expand "see more" text before extracting; descriptions are often truncated.
- Scroll lazy-loaded lists until the count stops growing.
- Dates appear as "Mon YYYY - Mon YYYY" or "Present"; keep the original text and add parsed fields.

## Editing tips
- Edit forms open in a dialog. Fill fields, then use the dialog's Save button, not Enter.
- After saving, reload the section page and compare with what was intended.
- Some edits offer "Notify network" toggles; leave them off unless the user says otherwise.
